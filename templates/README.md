# Note templates

Download a template's raw Markdown file, then import it with
**Settings → Import → Text & Markdown**. Choose a location and select **Continue**.
Edit the prompts in the imported page. You can import the file again for a fresh copy.

| Template | Use it for |
| --- | --- |
| [Meeting notes](meeting-notes.md) | Capture decisions and assign next steps |
| [Weekly review](weekly-review.md) | Review progress and plan the next week |
| [Project brief](project-brief.md) | Agree on an outcome and scope |

These files use ordinary Markdown headings, lists, tasks, and tables. They contain
prompts rather than app configuration. They can also be used in other Markdown tools.

See [import/export](../docs/import-export.md) or try a
[complete project-planning example](../examples/project-planning/README.md).
