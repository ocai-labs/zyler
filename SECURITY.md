# Security policy

## Report a vulnerability privately

Email [support@oceanai.so](mailto:support@oceanai.so) with a subject beginning
**Security report: Zyler**. Do not publish an issue containing vulnerability details,
credentials, or private notes.

Include the affected Zyler version and platform, the impact you observed, and the
smallest non-sensitive set of steps needed to reproduce it. Use sample data and
include a proof of concept only if it is needed to explain the issue.

Do not send passwords, session tokens, recovery keys, payment details, or a complete
personal vault. We may ask for additional information through the private conversation.

## Updates

Use the latest published release when checking an issue. Fixes are distributed in
[Zyler releases](https://github.com/ocai-labs/zyler/releases); older builds may not receive
separate fixes. Ordinary bugs and usage questions belong in [support](SUPPORT.md).
