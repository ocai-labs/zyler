# Get help with Zyler

Start with the [guides](docs/README.md) and [troubleshooting](docs/troubleshooting.md).

| You need help with | Contact |
| --- | --- |
| A reproducible app bug | [Bug report](https://github.com/ocai-labs/zyler/issues/new?template=bug-report.yml) |
| A feature or workflow improvement | [Feature request](https://github.com/ocai-labs/zyler/issues/new?template=feature-request.yml) |
| A general usage question | [GitHub Issues](https://github.com/ocai-labs/zyler/issues) |
| An account, billing, or private support question | [support@oceanai.so](mailto:support@oceanai.so) |
| A possible security vulnerability | [Private security report](SECURITY.md) |

For a bug, include the Zyler version from **Settings → General**, operating system
and architecture, steps to reproduce, what you expected, and what happened.
An example using an empty vault or non-sensitive sample note is especially useful.

GitHub reports are public. Remove private note content, login codes, tokens, account
details, and personal file paths from screenshots and logs. Do not upload your full
vault. Email private information only when it is necessary to investigate your request.
